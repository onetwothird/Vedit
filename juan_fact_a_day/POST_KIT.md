# Juan Fact a Day: Post Kit

## 1. Set up the Facebook Page (one time, ~5 min)
1. Facebook → Menu → **Pages** → **Create new Page**
2. **Name:** Juan Fact a Day
3. **Category:** Education Website (or "Media/News Company")
4. **Bio:** Araw-araw na kaalaman tungkol sa Pilipinas 🇵🇭 Facts, kasaysayan at kulturang Pinoy sa loob ng 60 segundo.
5. Upload `brand/juan_profile.jpg` (profile) and `brand/juan_cover.jpg` (cover)
6. Turn on **Professional mode** → later check **Monetization** in Professional Dashboard

## 2. Make the videos
Double-click `BUILD.bat` → each finished Reel (~60 s) appears inside its own folder in `stories/`.
To add a new one, see `README.md`.

## 3. Captions to paste
Each story folder has its own `caption.txt` (caption + hashtags + sources).

## 4. Posting / automation
- Post as **Reels**. Best times (PH): **12:00–1:00 PM** and **7:00–9:00 PM**.
- Use **Meta Business Suite → Planner** to schedule a week of Reels at once.
- Add trending music from Facebook's music library when uploading (keep it low).
- Reply to the first comments within an hour — it boosts reach.
